# Autonomous Agents

This project utilizes autonomous AI agents to accelerate the video editing and research process.

## AI Video Editor & Researcher
*   **Role:** Acts as a specialized video assistant.
*   **Capabilities:**
    *   Executes shell commands to run FFmpeg and Python scripts.
    *   "Views" extracted keyframe images to understand the visual context of raw footage.
    *   Correlates specific video scenes with narrative scripts to select the perfect B-roll.
    *   Generates Python scripts dynamically to compile final deliverables.
