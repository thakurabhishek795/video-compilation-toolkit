# Project Roadmap

Future enhancements for the video compilation toolkit:

*   **[ ] Automated Subtitle Generation:** Integrate OpenAI Whisper to automatically transcribe Dari/Pashto audio and generate SRT files.
*   **[ ] Advanced Audio Ducking:** Add capabilities to mix the voiceover script directly over the B-roll with automatic audio ducking of background noise.
*   **[ ] Auto-Scene Detection:** Replace fixed-interval keyframe extraction with algorithmic scene-change detection (e.g., `PySceneDetect`) to capture exact shot boundaries.
*   **[ ] Cloud Rendering:** Move the FFmpeg processing pipeline to a cloud instance for faster batch rendering of 4K assets.
